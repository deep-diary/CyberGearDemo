# 1 双编码器角度计算模块说明

## 核心变量

- **s_angleCalcHandle**: 角度计算模块的主句柄
- **outhMecAngle**: 输出机械角度，范围0-65535

## 主要功能

- 处理双编码器信号
- 计算精确的机械角度
- 支持角度校准

## 使用说明

1. 初始化角度计算模块
2. 配置相关参数
3. 调用计算函数获取角度值
4. 从结果中读取输出角度

# 2 速度控制和转矩控制

RequestedUserAppID 切换00，可运行速度和电流模式

默认为速度模式，通过BasicApp._super.pMCI.LastModalitySetByUser 切换控制模式 OX03是速度控制，OX04是转矩控制

启动是BasicApp.Flags.all 为1启动
BasicApp.SpeedREF是速度参考指令
BasicApp.Iref是电流参考指令

# 2 上电后自动校准

校准过后将iSCalibrationCompletedFlag设置为A0A0，存至flash中，如果未进行过校准，则从flash加载参数不为A0A0，开始自动校准

# 3 设置零位和回零功能

```c
/* 回零和零点设置功能结构体变量定义 */
HomingControl_t s_HomingControl = {
    .homingModeFlag = 0,     // 回零模式标志位
    .homingStartFlag = 0,    // 回零开始标志位
    .homingCounter = 0,      // 回零计数器
    .posRefSetSuccessFlag = 0, // PosRef设置成功标志位
    .posRefSetExecuted = 0,  // PosRef设置已执行标志位，防止重复执行
    .setZeroFlag = 0,        // 设置零点标志位
};
```
在任意模式和位置都可使用setZeroFlag去设置当前位置为0位
homingModeFlag切换为回零模式，homingStartFlag开始回零

# 5 磁编码器偏心校准且将校准结果存在flash中
偏心校准流程和之前的磁编校准相同，先切换模式再使能
```c
typedef struct {
  UserApplication_Handle_t _Super;
  ENCODER_Handle_t*        pEncoder;
  PositionProfileGenerator_Handle_t* pPosGen;

  uint32_t TimeStamp;
  uint32_t AlignmentDuration;
  uint32_t SpinningDuration;
  uint16_t AlignedMecAngle;
  int32_t IdrefStep;
  int32_t PosAccumulator;
  int16_t Idref;
  int16_t error;

  union {
    uint16_t all;
    struct {
      uint16_t Start         : 1;//校准开始
      uint16_t EnableSave2EE : 1;//校准结果存储
      uint16_t Rsvd          : 14;
    } bits;

  } flags;

  EAA_STATE_t state;
} EncoderAlignmentApp_Handle_t;
```
使能时，flags赋值3，即可开始校准并在校准完成后自动存储校准结果
